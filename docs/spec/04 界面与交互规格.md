# 04 界面与交互规格

本页规定 v1 每个界面的结构、状态与交互；视觉细节以设计稿为准，设计稿未覆盖处以本页为准。

## 主窗口布局

主窗口是固定的三栏布局：左侧会话侧栏、中间会话区、右侧可收起面板，上下为标题栏与状态栏。

&#91;embedded content: 主窗口线框 · 侧栏 + 会话区 + 右侧面板\]

黄色为只在等待审批时出现的审批卡，蓝色为始终存在的输入框。

| 区域 | 尺寸规则 |
| --- | --- |
| 窗口 | 最小 960 × 600；默认 1280 × 820，居中；记忆上次尺寸与位置 |
| 标题栏 | 40 px；macOS 使用 GPUI Kit `TitleBar` 并为红绿灯留出位置；Windows / Linux 自绘窗口控制按钮 |
| 侧栏 | 默认 280 px，拖拽范围 240–420 px；窗口宽度 < 1100 px 时自动收起 |
| 会话区 | 自适应；内容最大宽度 820 px 居中，左右内边距 ≥ 24 px |
| 右侧面板 | 默认收起；展开默认 360 px，拖拽范围 280–560 px；窗口宽度 < 1280 px 时以浮层 `Sheet` 形式从右侧滑出 |
| 状态栏 | 24 px；左：连接状态；中：后台任务数；右：当前模型与后端版本 |

间距以 4 px 为基数；字号：正文 14 px，辅助 12 px，标题 16 px；颜色只用 GPUI Kit 语义 Token。视觉稿由设计在阶段 0 结束前交付，与本页冲突时以设计稿为准。

## 侧栏

从上到下：工作区切换器、“新建会话”按钮、搜索框、视图筛选、会话列表、底部设置入口。

- **工作区切换器**：显示当前工作区名；点击展开列表 + “新建工作区…”。新建对话框：名称、目录（调用系统选择器），提交前 `workspaces:checkSlug`。当前工作区的“移除”置灰并提示“请先切换到其他工作区”。
- **视图筛选**：一组分段按钮“全部 / 未读 / 置顶 / 运行中 / 待审计划 / 归档”；“全部”不含归档与 `hidden` 会话。每个按钮右侧显示数量（为 0 时不显示）。
- **搜索**：输入即按标题本地过滤；停顿 300 ms 后发起 `sessions:searchContent`，正文命中以“内容匹配”分组显示片段；按 Esc 清空。
- **会话行**（高 52 px）：标题（单行省略）、预览或最后活动时间（相对时间）、状态标记。状态优先级：待审批（黄点）> 运行中（Spinner）> 待审计划（蓝点）> 未读（实心圆点）。置顶会话显示旗标图标。
- **排序**：按 `lastMessageAt` 降序；不单独置顶分组。
- **右键菜单**：重命名、置顶 / 取消置顶、标为已读 / 未读、归档 / 取消归档、在新窗口打开、导出、在文件管理器中显示、删除（红色，二次确认）。
- **键盘**：列表获得焦点后 ↑↓ 移动、Enter 打开、F2 重命名、Delete / Backspace 删除（确认）、Home / End 跳到首尾。
- **空态**：无会话时显示“还没有会话”与“新建会话”按钮；筛选无结果显示“没有符合条件的会话”。

## 会话区

**会话头部**（高 44 px）：会话标题（双击重命名；`title_regenerating` 时显示 Shimmer）、工作目录标签（点击修改）、右侧面板开关、更多菜单（分支、导出、删除）。

**消息列表**：内容区最大宽度 820 px 居中；行之间间距 16 px。三种行：

| 行类型 | 样式 | 内容 |
| --- | --- | --- |
| 用户消息 | 右对齐气泡，最大宽度 80% | 文本（badge 以 Tag 内联显示）、附件缩略图行。`isPending` 半透明；`isQueued` 虚线边框 + “排队中”标签。悬停显示复制、从此处分支 |
| 助手回合卡 | 全宽，无气泡 | 顶部“活动区”（工具卡、中间文本、状态），下方“答复区”（Markdown）。活动超过 3 条时，回合完成后自动折叠为一行摘要（“使用了 7 个工具 · 42 秒”），可展开 |
| 系统行 | 居中小字或卡片 | info / warning / status 用小字；error 用 `ErrorCard`；权限模式变更用 `Marker` 分隔线 |

**回合阶段与指示**（来自 `derive_turn_phase`）

| 阶段 | 显示 |
| --- | --- |
| pending | “思考中…” Shimmer |
| tool\_active | 运行中的工具卡显示 Spinner 与已用时间 |
| awaiting | “思考中…” Shimmer（工具间隙） |
| streaming | 答复区流式显示，末尾光标闪烁 |
| complete | 无指示；悬停显示复制、查看详情（回合 Markdown） |

**工具卡**：摘要行 = 图标 + 显示名（`toolDisplayName` 或 `toolName`）+ intent（灰字，单行省略）+ 耗时 + 状态图标（运行 / 成功 / 失败 / 后台 / 已拒绝）。点击展开显示“输入”（JSON，折叠长字段）与“结果”（见 03·agentkit-ui 渲染规则）。失败时结果区红色左边线。

**后台任务芯片**：在对应工具卡位置显示“后台运行 · 01:23”；点击在右侧面板“后台任务”标签显示输出（`getBackgroundTaskOutput`，运行中每 2 秒刷新）与“停止”按钮。

**右侧面板**（标签页）：文件（`sessions:getFiles` + `watchFiles`，树形，双击用系统应用打开）、计划（当前会话最新计划）、后台任务、扩展面板（框架注册）。

## 输入框

位于会话区底部，与消息列表同宽（最大 820 px）。结构自上而下：附件行（有附件时显示）、文本区、工具行。

- **文本区**：`Textarea` 自动增高，1–12 行，超出后内部滚动。占位文案随状态变化：空闲“输入消息，@ 提及文件，/ 使用 Skill”；运行中“继续输入会在当前回合后发送”。
- **发送键**：设置为 `enter` 时 Enter 发送、Shift+Enter 换行；设置为 `cmd-enter` 时 Cmd/Ctrl+Enter 发送、Enter 换行。输入法组字（IME composition）期间任何发送键都不生效。空内容且无附件时不发送。
- **附件**：回形针按钮（系统选择器，可多选）、粘贴（图片或文件）、拖入会话区任意位置（拖入时显示全区域接收提示）。附件以 `Attachment` 缩略图显示，可单个移除。
- **@ 提及**：输入 `@` 弹出候选，用工作目录调 `fs:search(basePath, query)`（防抖 150 ms），文件 / 文件夹分组；↑↓ 选择、Enter / Tab 确认、Esc 关闭。确认后在文本中以不可编辑的 Tag 显示，发送时转为 `[file:…]` / `[folder:…]`。
- **/ Skill**：行首输入 `/` 弹出 Skills 列表（名称 + 描述），另含内置命令 `/compact`。选中 Skill 后以 Tag 显示，发送时转为 `[skill:…]` 并加入 `skillSlugs`。
- **工具行**（左 → 右）：权限模式按钮（探索 / 询问 / 执行，点击弹菜单，Shift+Tab 循环；执行模式按钮为警示色）、模型选择器（按连接分组列出已认证连接的模型）、思考等级（off / low / medium / high / xhigh / max）、上下文占用环（悬停显示 token 明细）、发送 / 停止按钮（运行中变为停止）。
- **草稿**：文本或附件变化后 500 ms 调 `drafts:set`；发送成功后 `drafts:delete`；打开会话时 `drafts:get` 恢复。
- **历史**：空输入框按 ↑ 填入本会话上一条用户消息。

## 权限审批与计划审阅

**审批卡**（`PermissionPrompt`）出现在当前回合卡底部、输入框上方，样式为警示色边框卡片：

- 标题：“需要你的批准：<工具名>”；正文：`description`；有 `command` 时用等宽字体代码块显示；有 `reason` / `impact` 时分行显示。
- 按钮：“允许”（主按钮，Enter）、“本会话始终允许”（仅当 `canAlwaysAllow` 为 true；Cmd/Ctrl+Enter）、“拒绝”（Esc）。审批卡出现时自动获得焦点。
- 多个待审批请求按到达顺序排队，一次只显示一个，标题显示“1 / 3”。
- 点击后按钮立即置灰（防重复提交）；RPC 成功后卡片收起为一行“已允许 / 已拒绝 · <工具名>”保留在回合内；失败则恢复按钮并提示。
- 会话不在当前视图时，侧栏该会话显示黄点；窗口不在前台时发送系统通知。

**执行模式警示**：会话处于 `allow-all` 时，输入框上方显示常驻窄条“执行模式：Agent 将不经确认写文件和执行命令”，右侧“切回探索”。

**计划卡**（`PlanCard`）：以独立卡片显示在回合内，标题“计划”；正文为计划 Markdown；底部按钮“接受并执行”（主按钮）与“接受并压缩上下文后执行”（次按钮）。只有会话最后一条计划显示按钮；接受后按钮变为“已接受”。输入框中已有内容时，按钮下方提示“输入框中的内容将作为补充说明一起发送”。执行逻辑见 01 页 U4。

## 设置页与首次启动引导

**设置**：Cmd/Ctrl+, 打开，在当前窗口中替换主区域（侧栏变为设置导航，左上角“返回”）。使用 GPUI Kit `Settings` 组件。所有项修改即保存，无“保存”按钮。

| 分组 | 设置项 | 存储 / 频道 |
| --- | --- | --- |
| 通用 | 语言（简体中文 / English）、启动时打开上次会话、发送键 | 本地偏好；`input:setSendMessageKey` |
| 外观 | 主题（跟随系统 / 亮 / 暗 + 主题列表）、字号（12–16）、流式文字淡入 | 本地偏好 |
| 模型 | 连接列表（名称、类型、认证状态、默认标记）；添加 / 编辑 / 删除 / 测试 / 设为默认 / 刷新模型；默认思考等级；自动压缩阈值 | `LLM_Connection:*`、`settings:*` |
| 权限 | 当前工作区默认权限模式；内置策略只读展示 | `workspaceSettings:update(id, 'permissionMode', …)`；`permissions:getDefaults` |
| 网络 | HTTP 代理、HTTPS 代理、不代理列表、启用开关；保存后提示“将重启后端，运行中的会话会被中断” | `settings:setNetworkProxy`（补丁 P-01）→ 重启 sidecar |
| 通知与电源 | 回合完成通知、审批通知、运行时防休眠 | 本地偏好；`power:setKeepAwake`（补丁 P-02） |
| 快捷键 | 只读列表 + “打开 keymap.json” | 本地文件 |
| 高级 | 打开日志目录、导出诊断包、重启后端、崩溃上报开关（阶段 3） | 本地 |
| 关于 | 版本、检查更新（阶段 3）、开源许可 | — |

**连接编辑器**：类型选择（API Key 预设 / 自定义 OpenAI 兼容 / 自定义 Anthropic 兼容 / Ollama / ChatGPT Plus / Claude Pro·Max）决定表单字段：

| 类型 | 字段 | 映射（见上游 docs/connections.md） |
| --- | --- | --- |
| API Key 预设 | 供应商（`pi:getApiKeyProviders`）、API Key、默认模型（`pi:getProviderModels`） | `providerType: pi`，`authType: api_key`，`piAuthProvider` |
| 自定义端点 | Base URL、API Key（可空）、协议、模型列表 | `pi_compat`，`api_key_with_endpoint`，`customEndpoint.api` |
| Ollama | Base URL（默认 `http://127.0.0.1:11434/v1`）、模型 | `pi_compat`，`none`，`openai-completions` |
| ChatGPT / Claude | “登录”按钮 | `pi` + `oauth`，流程见 03·agentkit-capabilities |

API Key 输入框为密码模式，已保存的 Key 只显示“已设置”并提供“替换”；客户端不调用 `LLM_Connection:getApiKey`。

**首次启动引导**（全窗口，`Stepper` 4 步）：欢迎 → 选择连接方式（6 个大卡片）→ 填写并测试（测试失败显示后端返回的原因）→ 完成（显示“开始第一个会话”）。第 2 步右上角“稍后设置”调用 `onboarding:deferSetup` 后直接进入工作台，输入框置灰并提示“先添加模型连接”。

## 状态与异常态

| 场景 | 触发 | 界面 |
| --- | --- | --- |
| 启动中 | sidecar 未就绪 | 窗口内骨架屏（侧栏与消息区 Skeleton）+ 状态栏“正在启动后端…” |
| 重连中 | `Reconnecting` | 状态栏黄色“连接已断开，正在重连（第 n 次，x 秒后）”+ “立即重试”；输入框置灰，已显示内容保持可读 |
| 后端重启中 | `Restarting` | 同上，文案“后端已退出，正在重启” |
| 致命错误 | `Fatal` | 整窗阻断页：原因、“重试”、“打开日志”、“导出诊断信息”；`AlreadyRunning` 时文案说明数据目录被另一实例占用 |
| 会话加载中 | `getMessages` 未返回 | 消息区 Skeleton（超过 150 ms 才显示，避免闪烁） |
| 会话加载失败 | RPC 错误 | 消息区中央错误信息 + “重试” |
| 新会话空态 | 无消息 | 中央显示应用名与 3 个示例提示（点击填入输入框） |
| 无可用连接 | 已跳过引导 | 输入框位置显示“添加模型连接后即可开始”+ 按钮 |
| 连接认证失效 | `isAuthenticated=false` | 模型选择器中该连接显示红点；发送失败时的 typed\_error 带“去设置”按钮 |
| 回合中断 | `interrupted` | 回合卡底部灰字“已中断”；输入框恢复排队消息 |
| 上下文压缩 | `status` statusType=compacting | 系统行“正在压缩上下文…”+ Spinner；完成后变为“上下文已压缩” |
| 自动重试 | `retry` | 回合卡内“请求失败，正在重试…”（backoff 时显示 message） |
| 操作失败提示 | 写类 RPC 失败 | `Notification` toast，4 秒自动消失，错误类需手动关闭 |
