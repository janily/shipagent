# T-1-23 原生性能基准与 CI

基线为 PR #29 合并后的 `e20c2a5`，后端仍固定 v0.2.6。实现与测量边界见 [运行指南](../tools/perf/README.md) 和 [计划](plans/performance-ci.md)。本任务建设可重复的工程测量与告警，不关闭阶段0或参考硬件验收。

## 实现

真实 release 工作台通过既有 controller、认证 WebSocket、固定后端与 Pi 执行 Read，然后由本地模型按真实单调时钟输出 50 个明确定义的测试 token/s。首启偏好只写入隔离目录，明确延期引导；不会操作个人配置。记录实际 GPUI Draw/Present、流式更新、首帧和后端/夹具就绪观测。

独立 release 原生场景使用正式 WorkbenchView、SessionStore、ToolCard、ToolOutputView 和 FullToolEditor，加载十个百条会话、万条 Markdown 历史、至少120帧的确定性程序滚动和十万行工具结果。RSS 是该 UI 场景进程的快照，不含完整应用 controller/RPC/偏好/设置实体，不能据此验收生产进程内存预算。历史打开包含构造/索引/绑定与首次提交，不含磁盘/网络下载；滚动是程序化位置更新的实际提交频率，不是触控板延迟。

每项至少三次完整运行，保留全部原始数据并取中位数；任何缺失、无效构建、未完成回合、清理失败、节奏/内容/帧覆盖率不合格均使聚合无效。未配对 Present 计入缺失，帧计数必须为非负整数且总数一致。缺失数据不按零处理，也不会显示预算通过。

夜间、手动及相关 PR 在共享 Linux/macOS 构建 release 并上传报告。比较对象只选前一个 main schedule，包括失败/尚未完成的运行；手动执行不替代前夜，也不回退寻找更早的有利数据。硬件、cgroup、工作负载、窗口或测量源码指纹不同则不比较。耗时/内存增加或 FPS 降低严格超过 10% 告警。首次没有前夜基线也明确告警。

Linux 保留内核 subreaper 所有权监督。macOS 正常退出记录实际 owned sidecar supervisor 的关闭结果；这不是 orphan census。异常时先 TERM，宽限后 KILL 原生，停止后续样本/场景。可选参考任务要求 `disposable-machine-per-job` 运维合约和每次作业后销毁 OS，禁止持久个人桌面；配置标签本身不是物理 M1 验收证据。

[模型断流](perf/linux-t123-model-disconnect.json)按预期无效，正常关闭后剩余所属进程为0。[原生强杀](perf/linux-t123-native-crash.json)按预期 forced/无效，subreaper 回收1个孤儿进程，最终所属进程为0；forced 回合不会被当作性能样本。失败场景使用与最终 suite 相同的 workbench 二进制，场景程序修复没有修改生产工作台代码。

## 原生回调与失败分类

初次实测中，真实流式链路有效，但独立 UI 场景在帧回调内调用了只适用于渲染阶段的动画接口，导致 current-view 崩溃并缺失报告。用窗口刷新替代后，debug 完整场景成功；该 debug 结果仅验证执行路径，不用于性能验收。新增退出码策略回归，并用实际失败报告重放确认：原生崩溃、场景报告缺失或进程清理未验证必须 exit 1，使 CI 失败；完整但无效或超预算的测量才保留 exit 2 告警。

## 跨夜归档读取

upload-artifact 多路径输入使用共同祖先作为 ZIP 根目录，当前配置会把报告保存为 `perf/report.json`。下载器兼容该路径与扁平的 `report.json`，且要求归档中恰好只有一个已知报告条目；重复、歧义或未知路径全部拒绝，不挑选有利结果。新增真实 ZIP 字节经下载公开入口的回归测试：已观察旧路径实现失败，修复后两种合法层级成功，重复/歧义/未知路径仍拒绝。未解包任意路径，原有8MB大小限制保留。

## CI 缓存回归

初次 macOS 工程包 CI 从 Rust target 缓存恢复了旧打包目录，现有打包器正确拒绝覆盖，因此任务失败。新增构建前归档：只接受真实目录，将其整体移入 RUNNER_TEMP 的唯一目录后再构建；普通文件或符号链接会停止作业，旧产物不会被删除或覆盖。签名/公证与防覆盖规则不变。性能报告目录则在恢复缓存后清理自身生成输出，保证本次报告与重新下载的前夜数据均为新文件。修复经过独立双轴复核。

## 保持开放的门槛

所有报告保留 `referenceAcceptance: not_evaluated`。共享 Xvfb/lavapipe 和 macOS 虚拟显示不能替代物理参考机。app-entry 启动观测排除了加载器，夹具就绪包含模型端点配置，尚未建立真实冷启动到可输入的时间。控制器批次收到至后续提交不是网络事件延迟。完整生产进程空闲/十会话 RSS、物理显示/输入延迟、IME/无障碍、七天稳定性、Developer ID/公证/干净机验收继续开放。
