## 实现范围

`RpcClient` 提供 service、workspaces、sessions、drafts、files、skills、connections、oauth、settings 分组，共 79 个请求频道；events 提供 8 个事件流。所有方法使用生成频道常量、固定参数顺序和 Operation 策略，返回具体类型。连接绑定句柄直接传入门面，延迟写不能越过连接代际屏障。

默认每次调用超时 30 秒；发送 300 秒、存附件/导入/导出 120 秒、会话搜索 15 秒。只读调用仅在超时时重试一次，使用新请求 id；写入、watch、OAuth 和连接测试均不自动重试。只读调用总时长可能达到两次预算。

可选尾参数缺省时截断；send 的后置参数存在时，前面的附件槽使用空数组而非 null。明确 nullable 的模型/默认连接支持 null 清除。命令按具体分支解码返回值。连接写入的 `{success:false,error}` 转为 HANDLER_ERROR；工作台不能把失败结果当作成功。

生成链从 14 扩展到 35 个安全根类型，另保存 4 个仅 Schema 的敏感根类型。密钥、授权码、OAuth state/token 和可含认证信息的代理 URL 使用手写 SecretString DTO，Debug 脱敏；序列化只在出站边界暴露。生成器拒绝安全根间接引用敏感根。WorkspaceSettings 的直接导入适配逐字段校验类型和可选性；递归文件树单独采用 export 暴露，不修改后端源码。

工作台先通过完整生成 DTO 校验，再显式投影到临时 UI 模型。完整领域/reducer 迁移属于 T-1-06，自动恢复与快照合并仍属于 T-1-08/21。

## 契约与边界

以固定后端实际 handler 为准：会话列表含空 messages；会话查询可返回 null；unwatchFiles 无参数；连接修改返回操作结果。权限配置使用上游 Zod 的类型化投影。升级后端时需重新审查这些适配。

P-01/P-02 尚未集成，相关设置方法会遵守握手频道可用性检查；本轮不伪造成功。原生 OAuth 浏览器回调和权限 UI 不在此项。server:statusChanged/shuttingDown 上游尚无已实现的 payload 契约，保留 ServerNotice 的原始 RpcValue 参数，不依赖它们实现生命周期行为。
