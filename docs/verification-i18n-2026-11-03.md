# T-1-11 国际化管线验证（2026-11-03）

基线 main `60799eb`（PR #17 已合并）。实现03页国际化约定、05页 `i18n` CI 门禁与 F-42；阶段0及发布验收状态不变。

`cargo xtask i18n` 从固定上游 en/zh-Hans 与应用自有 en/zh-CN 资源生成UI的 rust-i18n JSON，仅输出实际引用键。自有键统一 `ak.`，源资源移至 agentkit-app/locales；使用上游原键的项目包括失败状态、工作目录、未读、取消与清空等。组件样板的全部文案进入同一管线。

调用统一为字面量 `t!("key", name = value)`，app/UI通过同一个 rust-i18n 后端与locale翻译。`{{var}}` 转换为 `%{var}`，中英文键/参数一致，缺失、未使用自有键、重复键、非字符串/嵌套资源、未支持的i18next格式显式失败。后台任务计数使用命名插值；无可用工作区的启动错误也已本地化。

AST检查覆盖所有平台/功能的app/UI源文件、组件样板和入口，不受本次编译平台影响；检查中文、英文句子及界面单词，保留字符串转换与局部初始化别名的可见文本上下文。诊断表达式仍收集嵌套翻译引用。非UI例外逐项记录具体文件/字面量/原因，失效例外失败。该门禁是源策略检查，并不对任意外部函数执行完整Rust语义数据流分析。检查命令不改写文件，生成结果漂移即失败。

验证包括转换/Unicode/重复参数、资源重复与类型错误、键/参数差异、源码原始字符串/嵌套宏/测试注释排除、转换/别名标签、诊断嵌套翻译、按需生成及只读漂移检查；原生运行时验证中英上游键、中文别名、命名插值与英文回退。工具与三平台最终结果见PR及导出证据。详见 [开发说明](../tools/i18n/README.md)。

本轮不改变shell布局、会话或后端协议；设置页语言切换入口仍按后续任务。下一项 T-1-12：ChatView、TurnCard 与 MarkdownView。阶段0参考机性能、物理桌面、签名/公证与发布门槛仍开放，PR #6 工程包保留。
