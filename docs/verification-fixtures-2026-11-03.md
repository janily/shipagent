# T-1-09 真实事件录制与回放验证（2026-11-03）

基线 main `e5d8b75`（PR #15 已合并）；固定后端仍为 mkagent v0.2.6。新增 `cargo xtask fixtures record <场景|all>` 与 `fixtures replay <目录>`，使用隔离临时配置、实际 sidecar/Bun/Pi 和本地 OpenAI SSE 脚本模型，不请求真实模型或生产工作区。命令与完整比较规则见 [录制说明](../tools/fixtures/README.md)。

14类必备场景均实际录制：纯文本、单工具、两个同时在途的工具、两层 spawn_session 子会话、工具失败、权限允许、权限拒绝、取消、回合中追加消息、重试、typed_error、计划、成功上下文压缩、后台 shell 完成。嵌套使用该后端实际支持的独立子会话和父/祖父关系，不冒充旧 SDK Task 的同会话 parentToolUseId 活动树。权限场景核实真实写入文件的有无；取消等待 interrupted；重试确认 backoff/active/end 三阶段；压缩必须收到 compaction_complete，错误“会话太短”不计成功。

每类提交 JSONL 原始事件、初始回放种子、`sessions:getMessages` 权威结束快照和来源元数据。子会话种子在首次观测时获取头部并清空消息，随后从已订阅流完整回放；不声称它是创建前的RPC快照。元数据保存固定上游、实际构建 server/Pi 哈希、模型/脚本哈希、产物哈希及场景事件证据；录制期间脚本改变会拒绝发布。仅替换临时根路径，原始 ID、时间戳与顺序保留。候选文件不计入已通过夹具。

回放逐事件比较索引缓存与完整 turns；结束后比较完整持久化 Message DTO。显式去除 id/timestamp、isPending/isStreaming/isQueued、该后端未向 text_complete 转发的 isIntermediate，以及客户端生成而后端不保存的 errorActions；其余错误详情、原始错误、可重试标志、附件、关联等字段均比较。工具/status/info 为此固定服务端不持久化的渲染行；取消未提交的增量也不作为持久化回复。比较前按原始时间排序，处理排队用户消息开始执行后更新时间戳、磁盘数组仍保留插入位置的差异。此规则公开记录，原始最终快照仍可检查被规范化字段。

离线测试覆盖全部14类回放/哈希/来源/证据，以及损坏JSON、缺失/未知/外来事件、缺失终止、内容篡改、场景冒名、错误详情/原始错误/可重试标志篡改。5项Node测试核对脚本模型行为。`AGENTKIT_RECORD_EVENTS` 显式开发录制使用后台IO且拒绝覆盖已有文件；控制器持有同一写入器跨重连复用，轮换token在新事件前注册脱敏；两个来源及轮换token有回归验证。常规日志不录制会话内容。

审查分别核对规格与工程规范，修复完整持久化字段比较不足、重连后录制停止及库错误类型问题；公开错误类型保留原因，比较失败仅报消息索引/字段名，避免打印消息内容。三平台 contract CI 新增全部14类重新录制、回放和证据上传；离线测试仍无需后端。本地最终计数与三平台结论见本轮PR和导出证据。
