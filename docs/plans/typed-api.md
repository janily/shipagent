# T-1-03 typed API implementation plan

Use executing-plans inline, TDD and one fresh whole-branch review. Base main4ff3409 (PR8 merged). Spec02 channel table and spec03 client facade; actual pinned backend signatures take precedence over shorthand table returns.

Goal: every v1 request/event channel has a typed facade using generated channel constants, exact positional arguments, fixed method timeout and explicit read-only retry policy. No native capability/OAuth browser flow UI, backend patch P01/P02, reducer migration or release acceptance is claimed.

1. DTO surface (tools/codegen/input/sources/schemas, xtask; api/types/secrets): extend safe upstream wire roots needed by API; capture sensitive schemas without generating plaintext credential Rust types; hand-modeled secret request/response wrappers use SecretString and redacted Debug. Support actual nullable results, enum values and heterogeneous command replies. Tests: generator drift/secret exclusion, secret serialize/redact, malformed DTO rejection. RED→GREEN then commit.
2. Facade groups (client api/{sessions,workspaces,connections,settings,files,skills,oauth,drafts,service,events}.rs): public RpcClient grouped accessors; exact optional suffix truncation; earlier array slots get explicit empty arrays only when later options require them, never null placeholders. Operation descriptors are the single timeout/read/write policy used by execution; reads retry timeout once via invoke_read_timeout, writes never retry. Tests run all channel methods through real TCP server, literal independently reviewed expected arguments/response fixtures; long timeout policies, nullable model distinction, unwatch no-arg source signature, missing backend patches, OAuth errors. Commit.
3. Consume facade and verification: WorkbenchApi delegates to groups, maps generated DTOs into existing prototype UI projections explicitly (full domain migration T1-06). No RPC strings outside facade. Keep connection-bound intent safety from T1-02. Real backend read/tool/persistence/cancel plus typed smoke requests; core/native/full-feature clippy/fmt/drift and three-platform CI; docs coverage report; one final review and Important RED→GREEN fixes; PR, no merge.

Preflight: codegen safe roots feed typed facade; schema-only secrets must never become generated Debug String fields. Group helpers must preserve bound RpcClient handle. Workbench adapter must validate raw wire DTO before discarding UI-unused fields. Unknown JSON exists only where upstream explicitly has dynamic config/tool data, not as a blanket return type.
Review focus: optional arguments with later slots present; business {success:false} must not become success; auth/token/code/state Debug; non-idempotent OAuth/setup/watch operations never retry; command variants with distinct returns; bound handles survive facade delegation. Each gets fixture/integration assertions.
