# T-2-06 附件流程

基线 PR #36 合并 ca60d93。依据 01·U5/F-26、03·app::files 与 04·输入区；用户授权继续开发和提交推送。

1. 后台受限读取选择/拖拽/粘贴文件，50 MiB 上限，图片生成 ≤256px PNG 缩略图；视图不读文件、不发 RPC。
2. 会话 Entity 保存有稳定 ID 的附件草稿，选择器返回绑定发起会话；移除与晚回执按 ID 隔离。
3. 发送逐个 storeAttachment，保留失败项并显示逐项 warning；成功项用服务器路径与缩放结果发送。全部失败且无文本不发空消息。发送拒绝保留草稿，ACK 只消费捕获的成功项，不消费新编辑。
4. 原生 Kit Attachment 行、用户消息缩略图、多选/粘贴/会话区拖入提示；文本粘贴及 IME 行为保持。
5. 读取、部分失败、附件单独发送和回执归属回归；真实后端与三平台 CI。跨重启自动草稿持久化按后续 T-2-08 实现。

既有 Windows 计划契约失败和重跑排队单独保留记录；不借新功能豁免。阶段0/P0与正式签名门槛继续开放。
