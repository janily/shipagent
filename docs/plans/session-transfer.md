# T-2-10 会话分支与导入导出

消息气泡的“从此处分支”使用所选用户消息。会话菜单快捷入口使用当前会话中最近一条已确认的用户消息。

文件菜单可导入当前工作区或导出活动会话。侧栏会话菜单也可以导出指定会话。导出使用固定后端提供的会话包，清除连接选择信息，保存到用户选定的位置。会话正文和文件仍是导出内容的一部分。

导入使用同一会话包格式。复制以源会话为父会话。移动沿用包中的父会话关系，源应用和源文件保持原样。导入清除源工作目录与模型连接选择，并使用询问权限模式。单个导入文件限制为 16 MiB，后端 RPC 帧限制同样适用。

真实后端契约通过 JSON 往返检查复制和移动的 ID、名称及父会话关系。三平台构建和回归见 PR #41。
